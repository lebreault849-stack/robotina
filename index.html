ROBOTINA

Asistente personal de inteligencia artificial para Windows.

¿Qué es ROBOTINA?

ROBOTINA es una aplicación de escritorio que ayuda a su propietario a organizar tareas, consultar información y gestionar conexiones autorizadas con plataformas digitales.

Integración con redes sociales

ROBOTINA busca permitir que el propietario conecte voluntariamente sus cuentas mediante los mecanismos oficiales de autorización de cada plataforma.

Entre las funciones previstas están consultar información del perfil, estadísticas disponibles y publicaciones permitidas para elaborar informes.

Las funciones dependen de los permisos concedidos por el usuario y de la disponibilidad de las APIs oficiales. Algunas integraciones todavía están en desarrollo.

Uso privado

La aplicación se desarrolla inicialmente para uso personal en Windows y no se ofrece actualmente como servicio público.
